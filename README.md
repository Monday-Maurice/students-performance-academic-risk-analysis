# 🎓 Student Performance & Academic Risk Analysis

## Project Overview

This project applies data analysis and machine learning techniques to identify students at risk of poor academic performance. Using the Student Performance dataset, the project explores the factors influencing academic success through exploratory data analysis (EDA), statistical analysis, data visualization, and predictive modeling.

The objective is to demonstrate how educational data can be used to support early intervention and improve student outcomes.

## Project Objectives

- Clean and preprocess student performance data.
- Explore patterns and relationships using EDA.
- Identify factors associated with academic risk.
- Build predictive models using Decision Tree and Random Forest.
- Evaluate model performance using classification metrics.
- Interpret feature importance to identify key predictors of academic success.

## Tools & Technologies

## Key Findings

- Previous grades (G1 and G2) are the strongest predictors of academic risk.
- Students with previous academic failures are more likely to be at risk.
- Higher absenteeism is associated with lower academic performance.
- Study time and parental education have relatively smaller predictive influence compared to previous grades.
